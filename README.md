# 프로젝트 소개

- 모작 게임 : 마인크래프트
- 게임 영상 : https://www.youtube.com/watch?v=_7l0hEsSyQ8
- 개발 언어 : C++
- 사용 그래픽스 API : 다이렉트X9
- 제작 기간 : 1달
- 나의 역할 : 파티클시스템, 이펙트, 풀링 기능

# 작업 내용

- 쉐이더 활용
  - 안개 구현
  - 스캔 기능 구현
- 오브젝트 풀링 기능을 만들어 파티클, 몬스터 등 자주 사용하는 객체들에 대한 메모리 비용 절감시켜 프레임 드랍 방지
- 포인트 스프라이트를 이용하여 파티클을 제작하였으며 인스턴싱을 적용하여 드로우콜 횟수를 줄임
